One original fortune-cookie line for a software developer, entered in make.fun's "Fortune Cookie Wisdom for Developers" bounty: "Your next bug is already in production. It is patient — it has read your code more carefully than you did."

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```

This writes the fortune to `/tmp/out/entry.txt`.
